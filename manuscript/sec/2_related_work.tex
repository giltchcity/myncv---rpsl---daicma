\section{Related Work}
\label{sec:related_work}

We organize prior work according to the two-level temporal structure of our
problem. D1 and D2 are complementary observation modes inside one continuously
running dynamic-mapping session: D1 models motion while it is observed, whereas
D2 infers a change revealed only after the robot revisits a region. D3 connects
completed independent sessions through persistent scene memory. A D3 system must
not only reconcile changes since the previous deployment, but also resume D1 and
D2 during the current one.

\subsection{Single-session dynamic mapping: D1 and D2}

Dense object-level SLAM has developed increasingly expressive representations
for D1. Co-Fusion maintains independent surfel models for a static background
and multiple rigid objects~\cite{runz2017cofusion}. MID-Fusion replaces these
models with object-level octree volumes and continuously estimates geometric,
semantic, and motion properties~\cite{xu2019midfusion}. EM-Fusion represents
rigid objects with local signed-distance volumes and derives probabilistic data
association and occlusion handling from an expectation--maximization
formulation~\cite{strecke2019emfusion}. These methods reconstruct observed
moving objects rather than merely removing them, but rely on continuous
object observations and do not infer changes that occur after a region leaves
the active view.

Feature-based dynamic SLAM instead emphasizes joint robot--object state
estimation. DynaSLAM~II tightly couples camera, static structure, moving-object
trajectories, and object structure, while maintaining temporal 3D bounding
boxes~\cite{bescos2021dynaslam2}. DynoSAM provides several smoothing
formulations for jointly estimating robot state, object motion or poses, and
scene structure~\cite{morris2025dynosam}. Complementary mapping approaches
construct conservative dynamic evidence: Dynablox detects moving points from a
spatio-temporal free-space estimate~\cite{schmid2023dynablox}, while volumetric
belief mapping fuses LiDAR moving-object predictions with a Bayes
filter~\cite{mersch2023volumetric}. These systems are strong D1 references, but
do not provide a complete hidden-change state when the transition itself is not
observed.

D2 requires comparing observations separated by a gap in the same running
session. Bore \etal model movable objects with linked local-motion and global-jump
processes while the robot observes only part of a large map~\cite{bore2019movable}.
Changing-SLAM combines current dynamic-object filtering with a Bayesian object
persistence map and long-term association inside ORB-SLAM3~\cite{soares2023changing};
its final map remains sparse and its evaluation focuses on localization.
Khronos provides the closest dense D1+D2 formulation. Its active temporal window
tracks continuously observed dynamics, whereas its global process reconciles
fragments across observation gaps using spatio-temporal and ray-based
evidence~\cite{schmid2024khronos}. The published problem is nevertheless one
continuous estimation process over $t=0,\ldots,T$ and does not define how a
completed Khronos scene state initializes an independent later session.

Recent Gaussian work is relevant as a representation trend, but is not directly
comparable to our metric-semantic mesh/volumetric evaluation. We therefore cite
only representative boundaries. 4D Gaussian Splatting SLAM is a strong D1
example that reconstructs observed temporal motion with static and deformable
Gaussian primitives~\cite{li2025fourdgsslam}. GaME addresses D2 by revising an
online Gaussian map after out-of-view changes and managing stale keyframe
evidence~\cite{yugay2026game}; it receives poses and panoptic segmentation from
external systems and does not retain D1 object trajectories. These works show
that Gaussian representations improve photorealistic dynamic reconstruction,
but do not yet connect complete D1+D2 sessions through persistent memory.

\subsection{Cross-session scene memory and map maintenance: D3}

Early long-term map-maintenance work updated geometric maps over repeated
surveys. Pomerleau \etal maintain point-wise static/dynamic probabilities and
local velocities in a non-semantic LiDAR point map~\cite{pomerleau2014longterm}.
A more recent ray-based approach, RBIF, estimates probabilistic interference
between LiDAR ray bundles and occupied voxels to update discretized 3D
localization maps while reducing erroneous holes~\cite{breitfuss2024rbif}.
These methods are important D3 geometric-map predecessors, but do not preserve
object identity, dense temporal object history, or a full D1+D2 scene model.

Object- and volume-centric methods reason more explicitly about persistent
scene content. Panoptic Multi-TSDFs initializes a later run from prior volumetric
submaps and updates inactive entities as persistent, absent, or
unobserved~\cite{schmid2022panoptic}; short-term object tracking is explicitly
outside its implemented scope. POCD maintains probabilistic object-level
volumetric maps for changes between robot traversals~\cite{qian2022pocd}, and
POV-SLAM jointly estimates robot pose and semi-static object consistency over
repeated visits~\cite{qian2023povslam}. ObVi-SLAM transfers persistent object
landmarks between deployment sessions for long-term localization~\cite{adkins2024obvislam}.
OASIS-Map associates objects across a completed previous session and a current
session and predicts static, appeared, disappeared, moved, and unknown
states~\cite{oh2026oasismap}; it remains concurrent under-review work and relies
on poses from a separate multi-session LiDAR SLAM system.

Gaussian maps have also been revised across visits. LT-Gaussian aligns an old
Gaussian map with a later LiDAR stream, detects emerging and disappearing
structure, and uses the processed old map as a prior for targeted map
optimization~\cite{cheng2025ltgaussian}. It is a useful D3 map-update reference,
but it neither reconstructs D1 histories nor distinguishes unobserved prior
geometry from evidence-confirmed absence. We omit the many closely related
Gaussian variants from the main discussion because their rendering-centric
outputs, inputs, and metrics do not form direct baselines for our dense
metric-semantic scene-memory task.

\subsection{Positioning of this work}

The closest single-session system is Khronos, which provides dense D1+D2
spatio-temporal mapping. The closest cross-session components are Panoptic
Multi-TSDFs, POCD/POV-SLAM, and related persistent object or geometric map
updaters. What remains missing is the recurring interface between these levels:
a complete D1+D2 session exports a persistent dense scene memory, an independently
started session reconciles D3 changes from that memory, and the new session
simultaneously resumes D1 and D2 before producing the prior for the next
deployment.
