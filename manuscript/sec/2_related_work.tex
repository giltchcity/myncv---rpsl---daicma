\section{Related Work}
\label{sec:related_work}

We organize prior work by the state that survives in time. The first family
builds rich dynamic representations while one mapping process remains active.
The second carries geometric maps across traversals. The third maintains richer
object or scene memories across time. Our problem lies at the interface: making
the \emph{dynamic mapping process} persistent across independently executed
sessions.

\subsection{Dynamic Mapping Within a Deployment}

Dense dynamic SLAM increasingly models moving entities rather than treating them
only as outliers. Co-Fusion maintains separate surfel models for a static
background and multiple rigid objects~\cite{runz2017cofusion}; MID-Fusion uses
object-level octree volumes and jointly estimates geometry, semantics, and
motion~\cite{xu2019midfusion}; and EM-Fusion combines local signed-distance
volumes with probabilistic data association and occlusion
reasoning~\cite{strecke2019emfusion}. Feature-based systems emphasize joint state
estimation: DynaSLAM~II tightly couples camera, object trajectories, and scene
structure~\cite{bescos2021dynaslam2}, while DynoSAM formulates joint robot and
object motion estimation in a factor graph~\cite{morris2025dynosam}. Recent 4D
representations extend this idea to non-rigid or photorealistic temporal scene
models, including dynamic surface Gaussians in 4DTAM~\cite{matsuki2025fourdtam},
4D Gaussian Splatting SLAM~\cite{li2025fourdgsslam}, DynaGSLAM~\cite{li2026dynagslam},
and persistent primitive-based reconstruction in 4D
Primitive-Mache~\cite{mazur2026primitive}. These methods provide increasingly
expressive forms of D1: the transition itself is observed and represented over
time.

Dynamic mapping also requires reasoning when the transition is not observed.
Bore \etal model intermittently visible movable objects using local-motion and
global-jump processes~\cite{bore2019movable}. Changing-SLAM combines dynamic
feature filtering, object tracking, a Bayesian persistence map, and long-term
association in a sparse SLAM system~\cite{soares2023changing}. Khronos provides
the closest dense formulation to our within-session setting: an active temporal
window handles observed dynamics, while a global process reconciles scene
fragments separated by observation gaps using spatio-temporal and ray-based
evidence~\cite{schmid2024khronos}. GaME addresses a related representation-level
problem by updating a posed RGB-D Gaussian map after out-of-view scene changes,
adding newly supported geometry and removing ray-contradicted
Gaussians~\cite{yugay2026game}. SuperMap and LTC-Mapping likewise maintain
object-level semantic or visibility-aware state over a continuous
stream~\cite{zhao2026supermap,matezbandera2022ltc}.

The important boundary for our work is not whether these systems contain a
particular tracking or update mechanism. It is temporal scope. Their rich dynamic
reasoning is defined while a mapping process or observation stream remains
active; they do not establish a recurring state contract through which a
completed dynamic-mapping session initializes an independent later session that
again executes the same full dynamic reasoning.

\subsection{Lifelong and Multi-Session Map Maintenance}

A complementary literature maintains maps over repeated traversals. Dynamic Pose
Graph SLAM edits outdated laser geometry while retaining a separate history of
added and removed points~\cite{walcott2012dynamic}. Pomerleau \etal estimate
point-wise dynamic probabilities over repeated LiDAR surveys and maintain a
long-term 3D map~\cite{pomerleau2014longterm}. Efficient Long-Term Mapping uses
free-space-aware local-cloud merging to suppress transient clutter and fuses
local maps across inter-session loop closures~\cite{lazaro2018efficient}.
LT-Mapper separates multi-session alignment, dynamic-object removal, and
positive/negative map-change management~\cite{kim2022ltmapper}, while RBIF uses
probabilistic ray--voxel interference for conservative long-term occupancy
updates~\cite{breitfuss2024rbif}.

More recent methods make this maintenance explicitly recursive. ELite estimates
local ephemerality to remove dynamic LiDAR returns and updates point-wise global
ephemerality in a lifelong map~\cite{gil2025elite}. ProbPer-LiLo models semantic
clusters as static or non-static, removes dynamic and quasi-static content, and
recursively refines prior and current static maps through semantic voxel
comparison~\cite{ali2026probperlilo}. LT-Gaussian transfers the same long-term
revision pattern to 3D Gaussian maps by aligning a new traversal, removing
outdated Gaussian centers, and initializing emerging geometry~\cite{cheng2025ltgaussian}.

These methods solve an important deployment problem: preserving a useful map
when the environment changes. Their dominant output, however, is a cleaned,
current, or geometrically revised representation for subsequent localization or
mapping. Rich observed motion histories and within-session hidden-change state
are not the persistent object of estimation. Thus map longevity and temporal
scene understanding remain largely separate concerns.

\subsection{Persistent Object and Scene Memories}

Object- and volume-centric systems retain richer state across time. Panoptic
Multi-TSDFs propagates active and inactive volumetric submaps between mapping
runs and distinguishes persistent, absent, and unobserved entities~\cite{schmid2022panoptic}.
POCD maintains object-level volumes and stationarity/change beliefs between
traversals~\cite{qian2022pocd}, while POV-SLAM jointly estimates robot pose and
semi-static object consistency over repeated visits~\cite{qian2023povslam}.
ObVi-SLAM transfers selected long-term object landmarks between deployments for
localization~\cite{adkins2024obvislam}. OASIS-Map builds separate object maps for
previous and current sessions, associates them through semantic correspondence,
and labels objects as static, moved, appeared, disappeared, or
unknown~\cite{oh2026oasismap}. Living Scenes instead performs offline object
association, registration, and reconstruction from scans captured at irregular
times~\cite{zhu2024livingscenes}.

Recent scene-memory systems further blur the boundary between mapping and
long-term recall, but their persistent state remains different from ours.
CogniMap3D detects and tracks dynamic regions in monocular video, then builds a
memory bank from \emph{static} point-cloud landmarks and visual/geometric
features; later visits retrieve a stored scene, relocalize against it, and merge
new static observations~\cite{wang2026cognimap3d}. Its goal is persistent static
spatial memory in the presence of dynamics, rather than persistence of dynamic
entity history. DGSG-Mind constructs an instance-aware Gaussian/voxel map and
hierarchical scene graph from posed RGB-D data, relocalizes later observations
against the Gaussian map, and performs localized object-level additions and
removals~\cite{ge2026dgsgmind}. This provides a strong current-scene memory for
long-term embodied tasks, but the method does not contain an integrated dynamic
tracking module and therefore does not preserve an observed D1 trajectory/state
across the update process.

Predictive persistence models address another complementary aspect of long-term
reasoning. Occupancy-grid HMMs learn transition probabilities~\cite{meyerdelius2012changinggrid},
FreMEn compactly models periodic environmental processes~\cite{krajnik2017fremen},
Spatio-Temporal Hilbert Maps learn continuous time-conditioned
occupancy~\cite{senanayake2016sthm}, and Perpetua maintains multiple hypotheses
for feature disappearance and reappearance~\cite{saavedraruiz2025perpetua}.
These models establish temporal persistence as a prior, but do not themselves
provide a dense scene representation that transfers a complete dynamic-mapping
process between deployments.

\subsection{Positioning of This Work}

The distinction that matters for our work is therefore not \emph{dynamic} versus
\emph{lifelong} as broad labels. Existing dynamic systems can preserve rich
temporal state while a deployment is active; lifelong systems can preserve and
revise maps across deployments; and recent object/scene memories can recall and
update substantially richer persistent representations. What remains missing is
the interface between these capabilities. We study \emph{persistent mapping}:
a complete dynamic-mapping session performs observed-motion and hidden-change
reasoning, exports persistent scene state when it terminates, and enables an
independently initialized later session to reconcile inter-session evolution and
again execute the same dynamic-mapping process before producing the prior for
the next deployment.
