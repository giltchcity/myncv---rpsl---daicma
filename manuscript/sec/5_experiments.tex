\section{Experiments}
\label{sec:experiments}

We test whether carrying scene state from one mapping run to the next preserves
useful geometry, removes obsolete object states, and continues to handle changes
during the new run. We use repeated real-room recordings, controlled synthetic
data with exact ground truth, and public RGB-D sequences.

\subsection{Datasets and Baselines}
\label{sec:datasets}

\paragraph{Repeated real-room runs.}
We use three RGB-D runs, A, B, and C, recorded in the same occupied room on
three days. The data contain 20 physical object identities, changes within each
run, and 16 annotated changed states between A and B. Object reference surfaces
are aggregated from depth during manually annotated presence intervals, using
2\,cm voxels observed in at least three frames. Scene geometry is evaluated
against a 1\,cm reconstruction from the measurements of each run. Run A builds
the initial map; B and C are later revisits.

\paragraph{Controlled synthetic runs.}
Two Isaac Sim sequences, A and B, revisit a furnished apartment with scripted
visible motion, changes that occur while the affected object is outside the
camera view, and changes between the two runs. A contains 4,186 frames and B
contains 4,041 frames at 30\,Hz. Per-frame object poses, visibility, and the
scene mesh are known exactly. The annotations contain 24 hidden changes in A,
10 in B, and 32 changes between A and B.

\paragraph{Public sequences.}
We use three 3RScan reference/rescan pairs~\cite{wald2019rio}: an unchanged
scene, a scene with two moved chairs and one removed chair, and a scene with a
non-rigid blanket change. We initialize the map from the reference scan and load
it for the rescan. Bonn RGB-D Dynamic~\cite{palazzolo2019bonn} provides short
box-manipulation sequences, and TUM~\cite{sturm2012tum} provides dynamic-person
sequences.

\paragraph{Baselines.}
We compare with the official Khronos release~\cite{schmid2024khronos} and
Panoptic Multi-TSDFs~\cite{schmid2022panoptic}. Khronos starts each run from an
empty map. Panoptic loads the previous map using the same supplied rigid
alignment as our method. \emph{Ours, from scratch} runs our method with the same
settings but without importing state from the previous run.

\subsection{Metrics}
\label{sec:protocols}

\paragraph{Object reconstruction.}
We report object precision, recall, and F1 with the Khronos online object
evaluator using a 2\,m surface-association gate.

\paragraph{Changed object states.}
For an annotated object-state surface $G$ and predicted map $M$, we measure the
fraction of sampled reference surface that is represented by predicted surface
of the same semantic class within 10\,cm,
\begin{equation}
 r(G,M)=\frac{|\{x\in G:d(x,M_{\ell(G)})\le0.10\,\mathrm{m}\}|}{|G|},
 \label{eq:representedness}
\end{equation}
where $M_{\ell(G)}$ denotes predicted surface with the class label of $G$ and
$|G|$ is the number of sampled reference points. A state is represented when
$r(G,M)\ge0.5$. A moved object contributes two events: disappearance of its old
state and appearance of its new state.

A \emph{hidden change} occurs within one run while the affected object is
outside the camera view and is scored when the region is observed again. A
\emph{between-run change} compares the state imported from one run with the
state reconstructed by the next run. Precision, recall, and F1 are computed over
appearance and disappearance events. \emph{Old-location residue} is
$r(G_{\mathrm{old}},M_{\mathrm{final}})$ for a state that should have departed;
lower values mean less obsolete surface remains at its old location.

\paragraph{Scene geometry.}
Geometry precision is the fraction of predicted surface samples within a
distance threshold of the reference, and recall is the fraction of reference
samples within the threshold of the prediction. We report their F1 at 5\,cm in
the tables and also evaluate 10 and 20\,cm. Real-room results use a room crop,
synthetic results use the simulator mesh, and 3RScan uses the rescan
reconstruction.

\subsection{Repeated Real-Room Mapping}

Carrying scene state improves object reconstruction in the later runs. Object F1
rises from 94.6 to 98.7 in B and from 96.4 to 98.6 in C relative to our
from-scratch runs. Compared with Khronos, the gains are 7.2 and 14.8 percentage
points. Hidden-change F1 is 100.0 in B and C, compared with 66.7 for Khronos.

Our method detects 15 of 16 changed states from A to B and all annotated changes
from B to C. Old-location residue is 6.8\% and 10.9\%, compared with 57.1\%
and 60.1\% for Panoptic. Geometry recall in B and C is 98.4\% and 98.9\%,
slightly above the 98.0\% and 98.4\% from-scratch results. Precision decreases
because small alignment errors can leave both the old and newly reconstructed
background surfaces in the map.

On the unchanged 3RScan scene, our method produces no false change. In Scene 2,
both moved chairs are represented at their new positions and all five unchanged
objects are retained; the removed chair is missed. Scene 3 produces one missed
and one spurious event. Geometry F1 is higher than Khronos in all three rescans.

Bonn and TUM provide single-run checks. In Bonn's placing sequence, the final box
state has represented-surface fractions of 1.00 for our method and 0.43 for
Khronos. In the moving sequence, both systems retain the first rest state because
the observed 0.75\,m motion is below Khronos's 1\,m displacement threshold. On
TUM \emph{walking\_xyz}, person contamination is 1.02\% for our method and
1.09\% for Khronos.
