\section{Experiments}
\label{sec:experiments}

We evaluate the current Khronos-based pipeline on five datasets. The experiments
ask whether persistent updates remove obsolete states, retain useful previous
coverage, and preserve mapping behavior during a new run. Khronos
~\cite{schmid2024khronos} supplies the single-run dynamic-mapping comparison;
Panoptic Multi-TSDFs~\cite{schmid2022panoptic} supplies a repeated-visit map-update
comparison. The scratch variant provides a reconstruction without an imported
map.

\paragraph{Real Kinect recordings.}
We record the same room three times. Run A lasts 133\,s; B lasts 135\,s and
is recorded about six hours later; C lasts 241\,s and is recorded about twelve
days after B. A starts from an empty map, B loads A's exported state, and C
loads B's state. Rigid transforms align B and C with A's coordinate frame.
Persistent object identities are supplied across runs.

The room contains 20 physical object identities. Hidden changes yield five
evaluated state events: one in A, two in B, and two in C, concerning the same
cabinet. Between A and B, seven moved objects, one addition, and one removal
produce 16 appearance/disappearance events. Between B and C, four moved objects
and two removals produce 10 events. Object reference surfaces are aggregated
from RGB-D measurements over manually annotated presence intervals.

\paragraph{Isaac Sim recordings.}
Two runs observe the same furnished apartment. A contains 4,186 frames and B
contains 4,041 frames at 30\,Hz. Both use ground-truth camera poses, semantics,
and instance IDs; B loads A's final state. The evaluated hidden changes contain
24 events in A and 10 in B. The revisit has 32 evaluated
appearance/disappearance events. These are evaluator event counts rather than
counts of all animations in the scene. The complete simulator mesh provides a
reference for geometry both inside and outside the current camera coverage.
% (double check) Keep frame counts and evaluated event counts tied to the exact sequence manifest used for each retained result.

\paragraph{Public recordings.}
For 3RScan~\cite{wald2019rio}, the reference scan builds the initial map and
the rescan loads it. We report three scan pairs: an unchanged scene, a scene with
moved and removed chairs, and a scene with additional object changes. Khronos
reconstructs the rescan from scratch. Bonn RGB-D Dynamic
~\cite{palazzolo2019bonn} and TUM~\cite{sturm2012tum} each provide single-visit
sequences, so they test behavior without importing an earlier map.

\subsection{What Each Metric Measures}
\label{sec:protocols}

\paragraph{Online object reconstruction.}
The Khronos evaluator associates same-class predicted and reference objects by
surface distance using a 2\,m association gate. Precision, recall, and F1 are
evaluated over time and weighted by state duration. This measures the online
object map, separately from the changed-state test below.

\paragraph{Changed object states.}
For reference surface samples $G$ and a predicted map $M$, let
\begin{equation}
 r(G,M)=\frac{|\{x\in G:d(x,M_{c(G)})\le0.10\,\mathrm{m}\}|}{|G|},
 \label{eq:representedness}
\end{equation}
where $M_{c(G)}$ is predicted surface with the semantic class of $G$, and
$d$ is distance to the nearest surface sample. A state is represented when
$r\ge0.5$. Moving one object gives two events: its old state disappears and
its new state appears. Removal and addition each give one event. We report event
precision, recall, and F1 for changes within a run and between successive runs.

\paragraph{Old-location residue.}
This measures the fraction of an old object surface still represented in the
final map at locations that later sensor measurements confirm to be empty.
Lower residue means less obsolete geometry remains. The observed-empty
locations are determined from the sensor observations, separately from the
method's own decision to retire a state.

\paragraph{Scene geometry.}
Precision is the fraction of predicted surface samples within a distance
threshold of the reference; recall is the fraction of reference samples covered
by the prediction. Their harmonic mean is geometry F1. All reported geometry
scores use 5\,cm. Simulation uses the complete scene mesh. Real-room references
are reconstructed from each run's RGB-D data, and comparison is restricted to
that run's observed region. The 3RScan reference is the rescan reconstruction.
% (double check) Keep the observed-region protocol as the primary real-geometry score in the final tables.

For Bonn, the final box state is measured with $r(G,M)$. For TUM, person
contamination is the fraction of final-map vertices projecting onto person-mask
pixels with agreeing depth in at least three evaluated frames.

Table~\ref{tab:real_d3} tests whether an imported map is corrected when the
room changes. Our pipeline detects 15 of 16 events from A to B and all 10 from

state transition is recognized and whether its obsolete surface is removed.

\subsection{What Coverage Does Memory Preserve?}

\begin{table}[t]
\centering\small
\caption{Geometry precision and recall at 5\,cm, in percent. Simulation uses
the complete scene reference. Real-room scores use the currently observed
region and that run's RGB-D reference.}
\label{tab:geometry_memory}
\begin{tabular}{llcc}
\toprule
Data & Method & Precision & Recall \\
\midrule
Synthetic B & Ours & 97.31 & 98.14 \\
Synthetic B & Ours, scratch & 96.92 & 78.47 \\
Real B & Ours & 89.92 & 98.68 \\
Real B & Ours, scratch & 95.55 & 98.37 \\
Real C & Ours & 86.46 & 99.13 \\
Real C & Ours, scratch & 92.57 & 98.71 \\
\bottomrule
\end{tabular}
\end{table}

The complete synthetic reference includes surfaces seen in A but not revisited
in B. Against this reference, our pipeline reaches 98.14\% recall, compared
with 78.47\% for the scratch result, while precision is 97.31\% versus
96.92\% (Table~\ref{tab:geometry_memory}). The largest difference is in scene
coverage, which is the intended role of memory where new observations are
absent.

The real-room comparison measures a different region: each reference contains
only surfaces reconstructed from that run. Earlier surfaces not revisited there
do not add recall. Recall differs by less than half a percentage point, while
precision is lower by 5--6 points. The recorded maps show duplicated background
surfaces and residual old states; rigid alignment leaves local errors between
old and new wall reconstructions. These results motivate selecting and
integrating valid evidence before extracting the combined surface.
