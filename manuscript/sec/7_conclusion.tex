\section{Conclusion}
\label{sec:conclusion}

An update layer lets an existing mapper follow a changing scene across runs. The layer decides which observations
still describe the scene and which elements of the earlier map continue, and the mapper integrates the selected
observations with its own rule. With the same decisions, a TSDF, a 3D Gaussian map, and an occupancy map remove
obsolete states, keep the regions that a new run leaves unobserved, and record when each state held. Any mapper that
provides the four operations of the interface can use the layer.
