\section{Introduction}
\label{sec:intro}

Long-term robotic mapping has a two-level temporal structure. Within every
continuously running mapping session, scene dynamics appear under two observation
modes. In the first mode, an object moves while it remains visible to the robot;
the system observes the transition itself and can represent the entity by a
trajectory, temporal bounding boxes, timestamps, and time-indexed geometry. In
the second mode, the robot observes an element, looks elsewhere while the same
SLAM session remains active, and later re-observes the affected region after the
element has moved, disappeared, or been replaced. The transition is then hidden:
only the scene before and after the observation gap is available. We refer to
these two cases as continuously observed dynamics (D1) and hidden
within-session change (D2). Together, D1 and D2 constitute the dynamic-mapping
problem inside one session.

A separate requirement arises across sessions. A mapping session may terminate
completely, the environment may change while the robot is absent, and a later
independent session must continue from persistent scene memory. We call this
inter-session evolution D3. D3 is not a third motion detector and is not created
by cutting a continuous sequence at an arbitrary time. It requires a completed
Session A to export sufficient scene state for an independently started Session
B to recognize changes since the previous deployment. Session B is itself a
complete dynamic-mapping session and must again handle both D1 and D2 while
producing the memory that initializes Session C.

The two intra-session modes require different inferences. Continuously observed
motion supports an actual trajectory. A hidden transition does not: if the old
location is later observed as free space and stable geometry appears elsewhere,
the honest interpretation may be an absence at the old location and a new
element at the new location unless identity can be established reliably.
Moreover, no match is not evidence of absence. Geometry must remain
\emph{unobserved} when the current trajectory provides insufficient visibility
and may be removed only when later measurements contradict it. D3 adds a
persistence requirement to this scene reasoning: the state required to
reconstruct the current scene and explain unresolved changes must survive
termination of the online SLAM process.

A large body of dynamic SLAM work addresses D1. Dense object-level systems
segment, track, and reconstruct moving entities~\cite{runz2017cofusion,xu2019midfusion,strecke2019emfusion},
while tightly coupled estimators jointly optimize camera state, object motion,
and scene structure~\cite{bescos2021dynaslam2,morris2025dynosam}. Recent 4D and
Gaussian methods further construct photorealistic or non-rigid temporal
representations from continuous image streams. These systems increasingly
capture what moved while it was observed, but D1 alone cannot determine what
happened while a region was outside the current view.

Several methods address changes revealed after an observation gap in the same
running process. Changing-SLAM combines dynamic-keypoint filtering and object
tracking with a Bayesian object-belief map and long-term data
association~\cite{soares2023changing}; its map remains sparse and its experiments
focus on localization robustness. Khronos provides the closest dense
single-session formulation. It factorizes one continuously running
spatio-temporal metric-semantic estimation problem into a fast D1 process and a
global D2 process~\cite{schmid2024khronos}. GaME similarly revises an online
Gaussian map after out-of-view changes, but receives poses and panoptic
segmentation externally and does not retain visible dynamic
trajectories~\cite{yugay2026game}.

SuperMap provides a complementary object-centric view of continuous-session
change~\cite{zhao2026supermap}. It processes one RGB-D or point-cloud stream,
associates open-vocabulary instances, recursively updates point occupancy and
semantic confidence, and records spatial and temporal object relations for
language-guided navigation. Its change experiment evaluates object additions and
removals during a ten-minute continuous run. SuperMap is therefore relevant to
online semantic identity and object-level change maintenance, but it neither
preserves dense D1 trajectories and temporal geometry nor defines a
process-separated Session-A export and independent Session-B restoration.

Long-term and multi-session methods instead concentrate on D3. Panoptic
Multi-TSDFs initializes later mapping from prior volumetric submaps and
distinguishes persistent, absent, and unobserved entities~\cite{schmid2022panoptic}.
POCD updates object-level volumetric maps for changes between traversals, while
POV-SLAM jointly reasons about semi-static objects and robot pose over repeated
visits~\cite{qian2022pocd,qian2023povslam}. ObVi-SLAM transfers persistent object
landmarks across deployments~\cite{adkins2024obvislam}, and OASIS-Map associates
objects and change states across completed mapping sessions~\cite{oh2026oasismap}.

ELite is an important point-level D3 predecessor~\cite{gil2025elite}. It aligns a
new LiDAR session to a previous lifelong point map, estimates local ephemerality
to remove current-session dynamic points, and recursively updates a global
point-wise ephemerality together with lifelong, static, and delta maps. Its
local/global ephemerality is not equivalent to D1/D2/D3: local ephemerality is a
dynamic-removal score rather than a representation of observed D1 trajectories
or hidden D2 transitions. ELite therefore provides a strong cross-session
geometric update baseline, but intentionally discards the dynamic history that
our target retains.

This leaves a narrower but practically important gap. Restarting from an empty
map discards valid historical coverage. Replacing the old map with the newest
reconstruction loses regions that the new traversal did not observe. Conversely,
unconditional map union preserves stale surfaces and duplicated objects.
Maintaining only a clean static map discards observed dynamic history, while an
object-only memory cannot update structural geometry. Pairwise change detection
is also insufficient: after an inter-session update, the new deployment remains
a dynamic SLAM session in which new D1 and D2 events continue to occur. A
long-term robot therefore needs a recurring process in which each session
consumes persistent scene state, performs complete single-session dynamic
mapping, and emits an updated state for the next deployment.

We formalize this problem as \emph{Persistent Spatio-Temporal Metric-Semantic
SLAM} (P-SMS). Let $\mathcal{S}^{k}$ denote the $k$-th independent mapping
session, with observations $\mathcal{Z}^{k}$, and let $\mathcal{M}^{k-1}$ be the
persistent scene memory produced by the preceding session. P-SMS seeks the
recurring update
\begin{equation}
    \left(\mathcal{M}^{k},\,\mathcal{H}^{k}\right)
    =
    \Phi\!\left(\mathcal{M}^{k-1},\mathcal{Z}^{k}\right),
    \label{eq:psms_update}
\end{equation}
where $\mathcal{H}^{k}$ stores the time-indexed D1 history observed within
session $k$, while $\mathcal{M}^{k}$ stores the current metric-semantic scene,
object and structural memory, unresolved evidence, and session provenance.
During session $k$, $\Phi$ must support both D1 and D2. Across the boundary from
$k-1$ to $k$, it must reconcile D3 by retaining previously valid but unobserved
content, removing inherited content only when contradicted by reliable current
evidence, incorporating genuinely new content, and preserving the information
required to repeat the same process in session $k+1$.

We instantiate P-SMS by extending dense single-session spatio-temporal mapping
with a persistent scene-memory and reconciliation layer. A completed session
exports stable geometry, object and structural memory, change evidence, and
session provenance. A later independent session loads this state as its prior,
reconciles inter-session changes using current surface and visibility evidence,
and concurrently runs the same D1+D2 machinery as before. D3 is therefore the
interface connecting complete dynamic mapping sessions, rather than an isolated
change detector or a static-map cleanup stage.

In the primary literature audited so far, existing systems either retain rich
dynamic histories inside a continuously running session or maintain and refine
clean geometric/object maps across deployments. To the best of our knowledge, no
existing \emph{dense metric-semantic SLAM} system exports the state required for
an independently initialized session to reconcile inter-session changes and
resume complete D1+D2 inference while retaining both dynamic history and current
structural geometry. Our contributions are:
\begin{itemize}
    \item We formulate process-separated persistent SMS, in which every session
    performs D1+D2 and exports the scene state required for recursive D3
    continuation.

    \item We develop a persistent scene-memory architecture that transfers dense
    current geometry, object and structural memory, change evidence, and session
    provenance between deployments.

    \item We establish an evaluation protocol that tests D1 and D2 within each
    session and recursive D3 across independent sessions, including current-map
    reconstruction, change-state estimation, preservation of unobserved regions,
    dynamic-to-static leakage, and cross-session update cost.
