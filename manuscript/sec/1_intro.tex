\section{Introduction}
\label{sec:intro}

A robot that maps the same environment repeatedly should not have to choose
between forgetting the past and keeping every old surface forever. Suppose a
robot maps a room, returns the next day, and finds that a chair has moved. Some
parts of the room are observed again, while others are not visited. A useful map
should preserve geometry that is still valid, remove the chair's old state when
later measurements show that the space is empty, and add the chair at its new
position. During the new run, the robot should also continue handling motion and
changes as in any dynamic-mapping run.

Dense dynamic mapping already handles many changes that occur during one run.
Systems such as Khronos reconstruct objects and background geometry, track
observed motion, and update the scene when objects appear or disappear after
observation gaps~\cite{schmid2024khronos}. Long-term mapping addresses another
part of the problem: carrying information between visits and updating an older
map when the environment changes~\cite{pomerleau2014longterm,lazaro2018efficient,
schmid2022panoptic}. We study how to carry a rich dynamic scene state from one
completed mapping run into the next without reducing it to either a fresh map
or a simple union of old and new geometry.

Our method stores successive geometric states of each object and updates them
with later depth measurements. Each object record contains its reconstructed
surface, the time interval in which it was observed, and the observations used
to build it. When a new run begins, its measurements are compared with the
stored states. Depth agreement supports an old surface, a closer measurement
indicates occlusion, and a farther measurement indicates that the old surface
is absent at that location. A new reconstruction is either merged with the
stored state or kept as a new state. Background geometry is handled similarly:
unobserved surfaces are retained, contradicted surfaces are removed, and newly
reconstructed geometry is added.

The next run loads more than a final mesh. It receives the object-state
registry, current background geometry, recorded history, and accumulated
measurement statistics used by the absence detector. The same scene history can
therefore continue to grow while the new run reconstructs its own motion and
changes.

We evaluate the method on repeated real-room runs, controlled synthetic data
with exact ground truth, and public RGB-D sequences. We measure temporal object
reconstruction, detection of changed object states, obsolete surface left at
former object locations, and scene geometry. The geometry scores also show the
trade-off between keeping previously observed surfaces and introducing duplicate
background geometry under imperfect alignment.

Our contributions are:
\begin{itemize}
    \item a representation for carrying dense object states, background geometry,
    and scene history from one dynamic-mapping run to the next;
    \item an evidence-based update rule that uses new depth measurements to keep,
    replace, or remove stored object states while preserving unobserved geometry;
    \item an evaluation on real, synthetic, and public data that measures object
    reconstruction, changed-state accuracy, obsolete-surface removal, and scene
    geometry across repeated runs.
\end{itemize}
