\section{Introduction}
\label{sec:intro}

When a chair moves, the map should reconstruct its new location, clear its old location, and retain the unchanged
room around it.
This requirement holds whether the robot sees the motion, discovers it after turning back, or returns on another
visit (\cref{fig:teaser}).
It also holds for any map representation: a truncated signed distance field (TSDF), a set of 3D Gaussians, or an
occupancy grid. Keeping earlier geometry indiscriminately leaves objects at outdated locations, while rebuilding from
scratch loses previously observed regions. Dynamic mapping must update the changed scene and
retain the parts that remain consistent.



Khronos reconstructs object fragments and reconciles them over time using a library of rays~\cite{schmid2024khronos},
while Panoptic Multi-TSDFs reasons about the presence of object submaps~\cite{schmid2022panoptic}.
GaME adds and removes Gaussians and filters outdated keyframe regions~\cite{yugay2026game}, while wavemap updates
occupancy through accumulated log odds~\cite{reijgwart2023wavemap}. These methods provide different ways to revise
geometry as the scene evolves. We seek a common update mechanism that applies to each representation and continues
when observations resume on another visit.

A scene change must revise both the map and the observations used to reconstruct it.
After the chair moves, its earlier images still describe the chair at the old location; using them to fit the current
scene can reconstruct it again. Yet those same images may still provide useful measurements of the unchanged wall.
The time interval in which a surface exists determines which geometry is current and which parts of each observation
remain compatible with it. This distinguishes a surface that has ended from one that is hidden or left unobserved.

We introduce \ours, a unified method for persistent dynamic mapping built around \emph{change detection} and
\emph{map update} (\cref{fig:method}). Change detection compares current depth with existing surfaces to establish
which object states continue, end, or begin. Map update applies these decisions to the object's reconstruction and to
the observations that can affect it. A confirmed change retires the old object's geometry, including parts outside
the current view. New observations reconstruct the new state, while compatible earlier observations continue to
complete unchanged surfaces. The method retains occluded and unobserved geometry until evidence supports an update.

The mechanism combines object-tracking and free-space motion cues with changes discovered against the retained map,
both within and across visits. The next visit resumes from the saved map
and state, and ended geometry remains available for queries at earlier times.
We implement these updates through TSDF fusion, Gaussian optimization, and occupancy integration.
Each representation uses its native reconstruction procedure; the shared mechanism determines its active geometry and
observation contributions. This separates the decision about scene change from the representation used to reconstruct it.

Real and synthetic sequences test changes within and across visits in the same evolving map;
Flat and 3RScan extend the evaluation to additional cross-visit changes.
All three representations improve geometry, object reconstruction, and change detection over their corresponding
baselines (\cref{tab:main}). During a partial revisit, retained geometry raises recall by 17.1--21.1 points
over native restart (\cref{tab:restart}). TESSE further evaluates temporal reconstruction using the official 4D
protocol. We examine Gaussian reconstruction in detail: novel-view rendering improves by 0.96--3.43\,dB PSNR
over GaME across all four datasets, and ablations establish the roles of change decisions and observation reuse.

Our contributions are:
\begin{itemize}
  \item A unified dynamic mapping method that handles changes within and across visits through shared updates
  to geometry and observation contributions in TSDF, Gaussian, and occupancy maps.
  \item An evaluation of both types of change in continuous reconstructions, complemented by public benchmarks,
  temporal evaluation, and detailed Gaussian reconstruction results and mechanism ablations.
\end{itemize}
