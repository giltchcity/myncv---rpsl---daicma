\section{Introduction}
\label{sec:intro}

The world does not reset when the mapper does.
Objects move while a robot watches, while it looks elsewhere, and between visits to the same space
(\cref{fig:teaser}). For a robot that repeatedly navigates and interacts with its environment, these
changes must become part of one evolving map. Maintaining that map requires following what changes
while preserving what remains, across both views and visits.

Khronos introduced the first real-time system for metric-semantic reconstruction of a scene over time~\cite{schmid2024khronos},
while GaME introduced the first mapping system with novel-view synthesis for evolving, long-term dynamic
scenes~\cite{yugay2026game}. wavemap combines state-of-the-art lossless occupancy compression with
efficient multi-resolution integration~\cite{reijgwart2023wavemap}. Across these representations, the shared
challenge is to reconcile new evidence with a reconstruction built from observations of an earlier scene.

Scene changes create conflicts between otherwise accurate observations. An earlier image of a chair and
a later image of the empty floor are individually correct, but they cannot both describe the current
scene. Continuing to use both without accounting for the change can preserve or recreate obsolete
geometry, while discarding the earlier image also removes observations of unchanged surroundings. The change must
therefore reach both the map and the observations that continue to reconstruct it.

We introduce \ours, a unified dynamic mapping method that uses scene-state intervals to connect these
two updates. Each interval records when an object remains in a particular configuration.
\emph{Change detection} checks retained surfaces against current depth and combines the evidence with
motion cues to determine which states continue, end, or begin (\cref{fig:method}). \emph{Map update}
uses these decisions to end obsolete geometry and restrict observation contributions to the states and
regions they describe. New observations reconstruct the changed scene, while compatible measurements
continue to complete unchanged surfaces.

The same state decisions govern TSDF fusion, Gaussian optimization, and occupancy integration.
Reconstruction continues across visits from the retained map and states, using the same updates for
changes observed during mapping and changes discovered on return. Geometry that is occluded or left unobserved is
retained until evidence supports an update; ended states remain available for queries at earlier times.

Our real and synthetic sequences combine changes within and across visits, while Flat and 3RScan extend
the cross-visit evaluation. Across these four datasets, all three representations
improve geometry, object reconstruction, and change detection over their corresponding baselines
(\cref{tab:main}). Partial revisits demonstrate greater completeness; TESSE evaluates temporal
reconstruction. Gaussian novel-view PSNR improves by 0.96--3.43\,dB over GaME
across the four datasets; ablations examine geometry retirement and observation reuse.

Our contributions are:
\begin{itemize}
  \item A unified dynamic mapping method that uses scene-state intervals to coordinate geometry and observation
  updates within and across visits, realized in TSDF, Gaussian, and occupancy reconstruction.
  \item An evaluation of continuous reconstruction under both types of change, with public benchmarks,
  temporal and completeness evaluations, and detailed Gaussian rendering results and mechanism ablations.
\end{itemize}
