\section{Introduction}
\label{sec:intro}

Long-term robotic mapping has a two-level temporal structure. Within every
continuously running mapping session, scene dynamics appear under two observation
modes. In the first mode, an object moves while it remains visible to the robot;
the system observes the transition itself and can represent the entity by a
trajectory, temporal bounding boxes, timestamps, and time-indexed geometry. In
the second mode, the robot observes an element, looks elsewhere while the same
SLAM session remains active, and later re-observes the affected region after the
element has moved, disappeared, or been replaced. The transition is then hidden:
only the scene before and after the observation gap is available. We refer to
these two cases as continuously observed dynamics (D1) and hidden
within-session change (D2). Together, D1 and D2 constitute the dynamic-mapping
problem inside one session.

A separate requirement arises across sessions. A mapping session may terminate
completely, the environment may change while the robot is absent, and a later
independent session must continue from persistent scene memory. We call this
inter-session evolution D3. D3 is not a third motion detector and is not created
by cutting a continuous sequence at an arbitrary time. It is the requirement
that a completed Session A export sufficient scene state for an independently
started Session B to recognize changes since the previous deployment. Session B
is itself a complete dynamic-mapping session and must again handle both D1 and
D2 while updating the memory that will initialize Session C.

The two intra-session modes require different inferences. Continuously observed
motion supports an actual trajectory. A hidden transition does not: if the old
location is later observed as free space and stable geometry appears elsewhere,
the honest interpretation may be an absence at the old location and a new
element at the new location unless identity can be established reliably.
Moreover, no match is not evidence of absence. Geometry must remain
\emph{unobserved} when the current trajectory provides insufficient visibility
and may be removed only when later measurements contradict it. D3 adds a
persistence requirement to this same scene reasoning: the distinction among
persistent, absent, unobserved, and new content must survive termination of the
online SLAM process and become available to the next independent session.

A large body of dynamic SLAM work addresses D1. Dense object-level systems
segment, track, and reconstruct moving entities~\cite{runz2017cofusion,xu2019midfusion,strecke2019emfusion},
while tightly coupled estimators jointly optimize camera state, object motion,
and scene structure~\cite{bescos2021dynaslam2,morris2025dynosam}. Recent 4D and
Gaussian methods further construct photorealistic or non-rigid temporal
representations from continuous image streams. These systems increasingly
capture what moved while it was observed, but D1 alone cannot determine what
happened while a region was outside the current view.

Several methods connect visible motion with changes revealed after an
observation gap. Changing-SLAM combines dynamic-keypoint filtering and object
tracking with a Bayesian object-belief map and long-term data
association~\cite{soares2023changing}; its geometric output nevertheless remains
an ORB-feature sparse map, and its experiments focus on localization robustness.
Khronos provides the closest dense single-session formulation. It defines
Spatio-Temporal Metric-Semantic SLAM (SMS) and factorizes one continuously
running estimation problem into a fast process for D1 and a slower global
process for D2~\cite{schmid2024khronos}. Visible motion is represented over time,
whereas changes that occur while the robot is looking elsewhere are inferred
when the affected region is revisited. GaME similarly updates a dense Gaussian
representation after out-of-view changes, but receives poses and panoptic
segmentation from external systems and does not retain visible dynamic
trajectories~\cite{yugay2026game}.

Recent semantic-memory systems narrow the gap further. SuperMap fuses geometric
SLAM with asynchronous open-vocabulary perception, maintains object identities
through geometric, existence, and semantic-confidence updates, and records
appearance, disappearance, relocation, spatial relations, and history in a
queryable 4D scene graph~\cite{zhao2026supermap}. Its public demonstrations show a
continuous campus-scale deployment and make it a major contemporary comparison
for persistent semantic memory. The remaining question for our problem is not
whether semantics can persist during a long run, but whether a completed dense
D1+D2 mapping process exports a sufficient state that an independently started
session can import and recursively update.

Long-term and multi-session methods concentrate on D3. Panoptic Multi-TSDFs
initializes later mapping from prior volumetric submaps and distinguishes
persistent, absent, and unobserved entities~\cite{schmid2022panoptic}. POCD
updates object-level volumetric maps for changes between traversals, while
POV-SLAM jointly reasons about semi-static objects and robot pose over repeated
visits~\cite{qian2022pocd,qian2023povslam}. ObVi-SLAM transfers persistent object
landmarks across deployments~\cite{adkins2024obvislam}, and OASIS-Map associates
objects and change states across completed mapping sessions~\cite{oh2026oasismap}.

ProbPer-LiLo is a particularly relevant recent development: it uses a discrete
probabilistic factor graph to classify object persistency and refine 3D maps from
multiple sessions~\cite{ali2026probperlilo}. These approaches provide strong D3
representations and update mechanisms, but primarily target stable geometric or
object maps rather than carrying a complete dense D1+D2 scene history into every
new deployment.

This separation leaves a practical gap for long-term robotic operation.
Restarting from an empty map discards valid historical coverage. Replacing the
old map with the newest reconstruction loses regions that the new traversal did
not observe. Conversely, unconditional map union preserves stale surfaces and
duplicated objects. Pairwise change detection is also insufficient: after an
inter-session update, the new deployment remains a dynamic SLAM session in which
new D1 and D2 events continue to occur. A long-term robot therefore needs a
recurring process in which each session consumes persistent memory, performs
complete single-session dynamic mapping, and emits an updated memory for the
next session.

We formalize this problem as \emph{Persistent Spatio-Temporal Metric-Semantic
SLAM} (P-SMS). Let $\mathcal{S}^{k}$ denote the $k$-th independent mapping
session, with observations $\mathcal{Z}^{k}$, and let $\mathcal{M}^{k-1}$ be the
persistent scene memory produced by the preceding session. P-SMS seeks the
recurring update
\begin{equation}
    \left(\mathcal{M}^{k},\,\mathcal{H}^{k}\right)
    =
    \Phi\!\left(\mathcal{M}^{k-1},\mathcal{Z}^{k}\right),
    \label{eq:psms_update}
\end{equation}
where $\mathcal{H}^{k}$ stores the time-indexed D1 history observed within
session $k$, while $\mathcal{M}^{k}$ is the updated current-scene memory that
survives process termination. During session $k$, $\Phi$ must support both D1
and D2. Across the boundary from $k-1$ to $k$, it must reconcile D3 by retaining
previously valid but unobserved geometry, removing inherited content only when
contradicted by reliable current evidence, incorporating genuinely new content,
and preserving the information required to repeat the same process in session
$k+1$.

We instantiate P-SMS by extending dense single-session spatio-temporal mapping
with a persistent scene-memory and reconciliation layer. A completed session
exports stable scene geometry, object-level memory, change evidence, and session
provenance. A later independent session loads this state as its prior, reconciles
inter-session changes using current surface and visibility evidence, and
concurrently runs the same D1+D2 machinery as before. D3 is therefore the
persistent interface connecting complete dynamic mapping sessions, rather than
an isolated detector operating after mapping has finished.

To the best of our knowledge, no existing \emph{dense metric-semantic SLAM}
system jointly provides (i) D1 time-indexed reconstruction of motion observed by
the robot, (ii) D2 reconciliation of changes occurring outside the robot's view
within the same running session, and (iii) D3 process-separated continuation in
which the exported scene state initializes an independent later session that
again performs D1+D2. Our contributions are:
\begin{itemize}
    \item We introduce P-SMS, a problem formulation with two intra-session
    dynamic modes, D1 and D2, connected across deployments by a persistent D3
    scene-memory update.

    \item We develop a persistent scene-memory architecture that transfers a
    dense current map, object memory, change evidence, and session provenance
    between deployments, while retaining complete D1+D2 processing inside every
    session.

    \item We establish an evaluation protocol that tests D1 and D2 within each
    session and D3 across independent sessions, including current-map
    reconstruction, change-state estimation, preservation of unobserved regions,
    dynamic-to-static leakage, and cross-session update cost.

\end{itemize}
