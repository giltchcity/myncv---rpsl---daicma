\section{Introduction}
\label{sec:intro}

A robot maps an apartment, leaves, and returns twelve days later. Meanwhile, someone has moved four pieces of
furniture and taken two away, and the bathroom is as it was. Whether the robot's mapper fuses a truncated signed
distance field (TSDF), optimizes 3D Gaussians, or accumulates occupancy, it offers two choices. It can reload the old
map, which leaves each moved object in two places, or start over, which discards every room the robot leaves
unobserved. A correct update removes what changed, keeps what is merely unobserved, and records when each state held.

Existing systems build this update into their own representation. Volumetric methods compare TSDF reconstructions to
find changed voxels~\cite{fehr2017tsdfchange}, keep object submaps that become persistent, absent, or
unobserved~\cite{schmid2022panoptic}, or estimate how stationary each object is~\cite{qian2022pocd}. Khronos verifies
object fragments against a library of earlier rays~\cite{schmid2024khronos}. GaME adds and removes Gaussians and masks
the stale regions of its keyframes~\cite{yugay2026game}. Occupancy mappers lower the occupancy of every cell that a ray
traverses~\cite{hornung2013octomap,reijgwart2023wavemap}. Each rule acts on its own primitives, so every new mapper
needs a new update rule.

Two questions decide every update, and neither depends on the representation. The first asks which observations still
describe the scene. A depth image of a chair was correct when the camera took it, but once the chair moves, the image
describes history and must stop shaping the current map. The second asks which parts of the earlier map remain. Where
the new run sees through an old surface, the surface is gone. Where the new run never looks, the earlier map is the
only evidence, and the old surface stays. Both questions concern observations and object states, not voxels or
Gaussians.

We therefore separate the temporal reasoning from the mapper. Our update layer runs beside an existing mapper and reads
the same RGB-D frames, camera poses, and instance masks. From these it infers when each object state holds, restricts
each observation to the space where its state still holds, and decides which elements of the previous map continue.
The mapper joins through four operations: it reports its elements, ends the elements the layer names, accepts the
object-state intervals, and integrates observations within their valid domains. It keeps its own integration rule. We
connect the layer to a TSDF mapper built on Khronos~\cite{schmid2024khronos}, to the Gaussian mapper
GaME~\cite{yugay2026game}, and to the occupancy mapper wavemap~\cite{reijgwart2023wavemap}. Because an ended element
keeps its lifetime, every map also shows the scene as it was at any earlier time.

With the same layer, all three mappers remove obsolete states and keep the coverage of earlier runs. On three
recordings of a real room taken over twelve days, the TSDF and Gaussian maps detect 15 of the 16 changes between the
first two runs and all 10 between the last two. The later runs still map their own changes: with the loaded state,
the TSDF map reaches object F1 \prov{99.2} and \prov{98.3}, against 91.5 and 83.8 for Khronos, which starts each run
from an empty map. After the revisits, \prov{1.6\%} and \prov{4.6\%} of the old object
surfaces remain in the TSDF, against 57.1\% and 60.1\% for Panoptic Multi-TSDFs~\cite{schmid2022panoptic}. In the
Gaussian map, \prov{6.5\%} and \prov{11.5\%} remain, against 42.4\% and 61.1\% under GaME's own update. On a simulated
apartment, where the second run observes only part of what the first run mapped, the updated maps recover \prov{98.4\%} (TSDF),
\prov{96.8\%} (Gaussians), and \prov{88.1\%} (occupancy) of the scene surface, against 74.1\%, 80.4\%, and
64.7\% for maps rebuilt from scratch. The Gaussian map renders the last run as well as a map rebuilt from scratch
(\prov{22.94} against 22.97\,dB) and \prov{0.81}\,dB better than GaME's update.

Our contributions are:
\begin{itemize}
  \item a formulation of persistent map updating that admits an observation only while the object state it measured
  holds and keeps an element of the earlier map until current observations place its surface elsewhere;
  \item an interface of four operations through which the same temporal decisions update a TSDF, a 3D Gaussian map,
  and an occupancy map;
  \item an evaluation on repeated real and simulated runs that compares, for each map, rebuilding from scratch,
  carrying the map over, the map's own update, and our update.
\end{itemize}
