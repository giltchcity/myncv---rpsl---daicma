\begin{abstract}
Robots that revisit changing environments need to keep useful geometry from
earlier runs without preserving object positions that are no longer valid.
Starting every run from scratch loses previous coverage, while simply
accumulating maps leaves stale geometry behind. We present a method for
continuing a dense dynamic map across separate mapping runs. Built on Khronos,
the method stores successive object states and background geometry, then updates
them with new RGB-D observations. New depth measurements projected onto previous
surfaces distinguish agreement, occlusion, and evidence that an old state is
absent. Evidence is accumulated before removing an object state, while
geometric comparison determines whether a new reconstruction refines the
previous state or represents a new one. On three real-room runs, F1 for object
changes between runs is 96.8\% and 100.0\%, compared with 64.0\% and 37.5\% for
Panoptic Multi-TSDFs, while old-location residue falls from 57--60\% to 7--11\%.
On controlled synthetic data, loading the previous scene raises geometry recall
from 78.5\% to 98.1\% at similar precision and detects 29 of 32 between-run
changes without a false event. The results show that dense dynamic scene state
can be carried across repeated mapping runs while remaining updateable by later
observations.
\end{abstract}
