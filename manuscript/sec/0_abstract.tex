\begin{abstract}
A mapper that returns to a changed scene can reload its old map, which keeps each moved object at its old site, or
start over, which discards every region it leaves unobserved. Existing methods resolve this conflict inside one map
representation, so each new mapper needs a new update rule. Two questions decide every update: which observations
still describe the scene, and which parts of the earlier map remain. Neither depends on the representation. We
present an update layer that answers both questions from the RGB-D frames and instance masks of a new run and leaves
integration to the mapper. The layer infers when each object state holds, admits an observation only while the state
it measured holds, and keeps an earlier map element until current observations place its surface elsewhere. A mapper
joins through four operations and keeps its own integration rule. We attach the layer to a TSDF, a 3D Gaussian, and an
occupancy mapper. On three recordings of a real room taken over twelve days, the share of old object surface that
remains in the Gaussian map falls from 42.4\% and 61.1\% under its own update to \prov{6.5\%} and \prov{11.5\%}. On a
simulated apartment, the updated maps recover \prov{96.8\%} of the scene surface with Gaussians and \prov{98.4\%}
with the TSDF, against 80.4\% and \prov{78.5\%} for maps rebuilt from scratch.
\end{abstract}
