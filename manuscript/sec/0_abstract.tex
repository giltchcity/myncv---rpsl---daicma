\begin{abstract}
The world does not reset when a mapper does. A robot that returns to a room may find the chair moved and the suitcase
gone. Reloading the old map keeps both at their old sites, and starting over discards every room the robot does not
revisit. Existing updates split the problem: they reason within one visit or carry a map without its reasoning, each for
one representation. We present \ours, a unified method for persistent mapping. Its core idea is that a change made while
the robot is away is decided like one made while it looks away. \ours infers when each object state holds, admits an
observation only while its state holds, and keeps an earlier map element until current observations place its surface
elsewhere. The map records where surfaces are, and \ours decides when they hold, so one method updates a TSDF, a 3D
Gaussian, and an occupancy map through four operations, and each map can be queried at any earlier time. Over three
visits to a real room, the TSDF keeps under \prov{7\%} of the surface of departed objects, against about 60\% for
Panoptic Multi-TSDFs. When the second visit to a simulated apartment sees only part of it, all three maps stay more
complete than under their published updates and far more complete than when rebuilt from scratch.
\end{abstract}
