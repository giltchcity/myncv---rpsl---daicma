\begin{abstract}
A robot returning to a changing room should retain the surfaces it does not
see again, remove objects that have disappeared, and record new motion during
its visit. Rebuilding the map loses earlier coverage, whereas simply combining
successive maps can preserve obsolete object positions. We present a method for
continuing dense dynamic scene maps across independently started deployments.
Built on Khronos, it carries forward object surfaces and their temporal
histories, background geometry, and sensor statistics. New depth observations
are projected onto stored object surfaces to distinguish geometric support,
free-space contradiction, and lack of visibility. An object-specific model of
measurement inconsistency accumulates evidence before declaring a stored state
absent; a separate geometric test decides whether a newly reconstructed object
refines its previous state or replaces it. We evaluate the mapping backend with
supplied camera poses, cross-session alignment, and persistent instance labels.
On three real-room deployments, cross-session change F1 is 96.8\% and 100.0\%,
compared with 64.0\% and 37.5\% for Panoptic Multi-TSDFs; remaining surface at
departed object locations falls from 57--60\% to 7--11\%. Synthetic and selected
public sequences provide complementary tests. The results also expose a cost
of the current representation: retaining separately reconstructed background
meshes improves coverage but can duplicate misaligned walls. The method thus
advances cross-deployment scene maintenance while leaving geometric fusion and
uncertain identity association as open system limitations.
\end{abstract}
