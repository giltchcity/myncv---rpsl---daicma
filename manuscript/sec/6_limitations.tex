\section{Limitations}
\label{sec:limitations}

The layer relies on inputs that it does not estimate: camera poses, a rigid transform that aligns each run with the
previous one, and instance masks whose identities persist across runs. On the real runs, residual misalignment places
repeated surfaces a few centimeters apart. A wrong identity links the states of two objects, and a missing one leaves
two copies of a moved object whose old site stays unobserved. The layer also inherits the errors of its state decisions: a missed change
keeps obsolete observations in use, and a false change removes valid ones. The layer models rigid objects that change
state. It does not model non-rigid deformation, gradual changes such as lighting, or changes smaller than a voxel. An
object carried in view is resolved only after it comes to rest, by the same test as a change out of view; the layer
records trajectories for people but not yet for carried objects. We evaluate one real room and one simulated
apartment, so large outdoor scenes and memory growth over many runs remain untested. Finally, each mapper needs an
adapter for the four operations, and the adapters for 3D Gaussians and occupancy change how these mappers train and
when they clear space.
