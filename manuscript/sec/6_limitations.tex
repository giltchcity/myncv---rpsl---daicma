\section{Limitations}
\label{sec:limitations}

The layer relies on two inputs that it does not estimate: instance masks whose identities persist across runs, and a
rigid transform that aligns each run with the previous one. On the real runs, residual misalignment places repeated
surfaces a few centimeters apart, which lowers precision against the real references. The layer also inherits the
errors of its state decisions. A missed change keeps obsolete observations in use, and a false change removes valid
ones. An object that moves in view by less than the motion-extraction threshold keeps its first rest state. Finally,
each mapper needs an adapter for the four operations, and the adapters for 3D Gaussians and occupancy change how these
mappers train and when they clear space.
