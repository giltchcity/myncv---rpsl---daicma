# Goal

Written 2026-09-21 after reading the manuscript intro and related work, and after
being told that the geometry-F1-versus-Khronos framing was the wrong axis.

## The paper's claim, restated so the work can be checked against it

Persistent *mapping*, not persistent *maps*. A completed session exports scene
state -- current geometry together with object and structural state, temporal
scene information, observability/change evidence and provenance -- so that an
independently initialised later session can reconcile inter-session evolution and
then run its own observed-motion and hidden-change reasoning again. D3 is the
interface between complete dynamic-mapping sessions, not a third detector. The
output of a session is the prior state of the next session, and the map answers
what the world was like at a query time rather than storing a union of
observations.

Novelty sits in three layers and must not be confused:

1. **Problem / idea.** Recursive persistent 4D mapping: `(M^k, H^k) = Phi(M^(k-1), Z^k)`,
   every session solving D1, D2 and D3, the map committing to query-time state.
2. **Algorithm.** How does a *deformable* persistent memory become a query-time
   estimator again on revisit? This is the layer that is currently missing, and
   it is what the method section has to contain.
3. **Implementation primitives.** TSDF, PGMO, active window, ray casting,
   marching cubes, GTSAM, nearest-neighbour search. These are borrowed on
   purpose. A prior-art search exists to stop us claiming a primitive, not to
   decide how ambitious the paper is allowed to be.

## The symptom to explain

The same code gives opposite verdicts on the two datasets.

| | synthetic AB (true GT, exact poses) | real ABC (1cm pseudo-GT, estimated alignment) |
|---|---|---|
| geometry | ours 0.9760, Khronos 0.8364, Panoptic 0.9210 | memory gated F1 0.9663, scratch 0.9664, Khronos 0.9637 |
| | | memory plain F1 0.9553, scratch 0.9606, Khronos 0.9583 |
| D2 hidden | F1 0.9231 (A), 0.9091 (B) | never measured |
| D3 | F1 0.9375 | never measured |
| D1 observed motion | **trajectory coverage 0.0** (Khronos 0.6455 / 0.5595) | never measured |

Memory is worth +14 pp on synthetic and +0.18 pp of recall on real. Two causes,
only one of which is an algorithm defect.

### S1 The real reference cannot reward memory (not an algorithm problem)

The real pseudo-GT is reconstructed from the *same session's* depth images, so it
holds no surface where that session did not look. Measured on stage B: memory's
exclusive surface is 2.1 m2, 90.8% of it never exposed by any B ray, 96.2% of it
farther than 5 cm from the reference, only 7.4% of it ray-contradicted. It is
charged as false positive and earns no recall. On synthetic the GT is the true
scene at the query time, including unobserved regions, so the identical mechanism
is rewarded. No parameter can change this; it is a property of the reference.

### S2 Real data carries an error synthetic does not: non-rigid inter-session deformation

Synthetic poses are exact. The real chain goes through an estimated alignment,
and the pseudo-GT self-consistency floor puts static co-observed surface more
than 5 cm apart on 10.2% of A->B, with the disagreement high-frequency rather
than a global offset. Memory's cost sits at exactly that scale: shells at
2--8 cm (1.5 m2) and 8--15 cm (0.9 m2, 37.5% ray-contradicted). `MemoryRegistration`
applies one rigid correction, which cannot absorb high-frequency non-rigid drift.

This also explains why mesh-normal seeding is adequate on synthetic and produced
12.17% phantom surface on thin real geometry: **after a non-isometric deformation
a surface no longer implies a consistent signed field, so its normals are the
wrong quantity to ask.** Surface geometry alone is insufficient to reconstruct the
observation field.

## Goal

Make inherited geometry behave as a query-time estimator on real data, where the
archive has been compressed to a globally deformable surface and the current
session may confirm, contradict, or never revisit it.

Concretely, the algorithm layer has to answer: given an archived surface `S`, the
historical visibility evidence `R` that produced it, and the global deformation
`D` that has since been applied to both, how do we recover a signed volumetric
field on the revisited region that the current measurements can refine? Lifting
from `(S, R, D)` rather than from `S` alone is the candidate, because `R` carries
the free-space/occluded distinction that `S` lost, and because deformed rays
deform consistently with the deformed surface while normals do not.

The fusion that follows is deliberately ordinary, and that is the point: one
estimator has to produce all three outcomes without a rule for any of them --
current evidence agreeing with memory yields one zero crossing instead of a
shell, current free space removes stale surface, and absent current evidence
leaves memory untouched.

## Acceptance

Nothing is accepted unless both datasets hold or improve. Real ABC and synthetic
AB are reported together, every time, with geometry and the object/change/state
metrics, not geometry alone.

Real ABC, versus the from-scratch map of the same session:
* shell mass at 2--15 cm falls from 2.4 m2, and the ray-contradicted part of it
  (0.9 m2, 37.5% contradicted) falls faster than the rest;
* plain precision loss versus from-scratch falls below the current 1.24 pp, of
  which only ~0.35 pp is attributable to real error;
* stale-surface removal rises from 36.8% toward the 40.5% that from-scratch
  achieves, without R_persist falling more than 0.2 pp.

Synthetic AB: geometry F1, D2 and D3 all hold; phantom surface stays far below
the 12.17 pp that mesh-normal seeding produced.

## Open items that are not the algorithm story but must not be forgotten

* **D1 observed dynamics is 0.0 on synthetic for us** while Khronos reports 0.6455
  and 0.5595. Contribution 1 of the intro claims D1 is modelled in every
  deployment. Cause unverified; `save_active_window_objects: false` is set in both
  mapper configs and is the first suspect. This is a hole in a stated
  contribution and is independent of the geometry work.
* Real-data object/change/state metrics have never been measured at all. D2 and
  D3 numbers exist only on synthetic.
* 0.45 pp of recall on genuinely persisting real surface is unexplained. Four
  candidates are measured and dead: the evidence threshold (0.11 pp), all
  background deletion (0.23 pp and costs precision), block seams (ratio 1.19,
  flat), the object layer (94.2% of the miss is covered by Khronos's background).
